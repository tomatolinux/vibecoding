# 가계도·생태도 편집기

브라우저에서 가계도(genogram)와 생태도(eco-map)를 그리고 **JPG / PNG / SVG** 이미지로 내보내는 웹 편집기입니다.
`index.html` 파일 하나로 동작하며 외부 라이브러리나 서버가 필요 없습니다.

## GitHub Pages로 바로 실행하기

1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `genogram-editor`, Public
2. **Add file → Upload files**로 `index.html`(와 이 README)을 올리고 Commit 합니다.
3. 저장소의 **Settings → Pages**로 갑니다.
4. **Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<GitHub아이디>.github.io/<저장소이름>/` 주소로 접속하면 바로 실행됩니다.

PC에서는 `index.html`을 더블클릭해서 브라우저로 열어도 그대로 쓸 수 있습니다.

## 주요 기능

- **사람 기호**: 남성, 여성, 성별 미상, 임신, 자연유산, 인공유산
  - 나이(도형 안), 이름·메모(아래), 출생–사망 연도
  - 사망(×), 클라이언트(이중선), 질환·약물 남용 칠하기
- **가족 구조선**: 결혼, 동거, 약혼, 별거(/), 이혼(//), 자녀(친자녀·입양·위탁)
- **정서적 관계**: 친밀, 밀착, 소원, 단절, 갈등, 밀착-갈등, 적대, 학대·폭력
- **생태도**: 원·사각형 체계, 강한·보통·약한·스트레스 관계선, 자원·에너지 흐름 화살표(→ ← ↔)
- **빠른 추가**: 사람을 선택하고 배우자·아들·딸·부모·형제를 한 번에 추가
- **범례**: 사용한 기호만 모아서 자동으로 그림(내보낸 이미지에 포함)
- **편집**:
  - 실행 취소/다시 실행, 복제(Ctrl+D), 정렬, 격자 맞춤
  - 자동 저장(브라우저)
  - 저장/열기(.json)

## 사용법 요약

| 동작 | 방법 |
|---|---|
| 사람·체계 추가 | 왼쪽 도구 클릭 (화면 가운데에 추가) |
| 선 연결 | 선 도구 선택 → 첫 번째 대상 → 두 번째 대상 클릭 |
| 자녀 연결 | `자녀 연결` 선택 → 부모의 혼인선 → 자녀 클릭 |
| 이동 / 화면 이동 | 대상 드래그 / 빈 곳 드래그 |
| 범위 선택 | Shift + 드래그 |
| 확대·축소 | 마우스 휠, 오른쪽 아래 `− 맞춤 +` |
| 삭제 · 도구 해제 | Delete · Esc |
| 이미지로 저장 | 위쪽 `JPG 내보내기` (PNG, SVG도 가능) |

## 참고

- 작업 내용은 **사용하는 브라우저에만** 자동 저장됩니다. 다른 기기에서 이어서 작업하려면 `저장`으로 .json 파일을 받은 뒤 `열기`로 불러오세요.
- 예시 화면은 바로 열 수도 있습니다: 주소 끝에 `#sample-genogram` 또는 `#sample-ecomap`을 붙입니다.
- 예시의 가족은 기능을 보여주려고 만든 가상의 가족입니다.
